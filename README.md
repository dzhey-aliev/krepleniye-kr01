# Крепление системного блока — КР-01.00.00

Сварная сборка из листа Ст3сп5 s5. Габарит 470 × 275 × 590 мм, масса ≈ 8,2 кг.

- **[Интерактивная 3D-модель](https://dzhey-aliev.github.io/krepleniye-kr01/)** — вращение ЛКМ, сдвиг ПКМ или Shift+ЛКМ, зум колесом. Размеры включаются галочками в панели справа.
- **[Сборочный чертёж КР-01.00.00 СБ (PDF, A3, 1:5)](chertezh-KR-01-00-00.pdf)**

## Состав

| Поз. | Наименование | Кол. |
|---|---|---|
| 1 | Основание — гнутая деталь, лист s5 | 1 |
| 2 | Ребро вертикальное 5×15×580 | 4 |
| 3 | Ребро горизонтальное 5×15×230 | 4 |

## Ключевые требования

1. Шов угловой Т1 по ГОСТ 14771-76, катет 3 мм. Сплошной по 80 мм от каждого конца ребра, в средней части прерывистый 30/100 вразбежку.
2. Верхние плоскости обеих полок выдержать в одной плоскости, отклонение не более 0,5 мм — это посадочная поверхность под 4 винта М6.
3. Порядок наложения швов симметричный, вразбежку — во избежание сварочных деформаций.
4. Радиусы гибов R5, если не указано иное.

Страница полностью автономна: файл `index.html` работает и локально, без интернета.
